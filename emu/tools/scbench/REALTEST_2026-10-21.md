- Why not FIFO: `_realtime` runs before the core opens RS1, so every librealsense thread the core creates inherits FIFO 50
  on the same cpu and they stop time-slicing. That gave 15x more late decisions plus dropped frames. Moving those threads off cpu 7

- **Hot-surface alert:** since 22:40 dmesg toggles `thermal cooling_device11: hot-surface-alert cooling state 0 <-> 1`
