# Walls STL Prior Assist

**Status**: Landed (default OFF)  
**Module**: `src/perception/walls_stl_prior.py`  
**Gate**: `KEVIN_WALLS_STL_PRIOR=/path/to/walls.stl`

## Overview

Optional static walls mesh (STL) prior for SLAM/localization assistance. Helps localization against known static walls without requiring a frozen house mesh and without treating the mesh as mandatory.

**Key principles**:
- Default OFF (fail-closed)
- Assists when available, never required
- No hot-path performance impact
- Does not etch movers into map

## Usage

### Basic Setup

```bash
# Enable walls prior
export KEVIN_WALLS_STL_PRIOR=/path/to/casitahouse-walls-fixed.stl

# Run Kevin with SLAM enabled
python3 src/vision.py
```

### How It Works

1. **Load** — `WallsSTLPrior` loads STL mesh on startup if env var set
2. **Extract** — 3D triangles → 2D wall line segments (project to xy plane)
3. **Project** — Wall segments projected to map pixel coordinates
4. **Inject** — Wall evidence drawn into map after loop closure / rebuild

### Wall Evidence Injection

- Triggered after SLAM loop closure + map rebuild
- Wall segments drawn as moderate obstacle evidence (value=128)
- Does not override fresh observations
- Helps fill in static structure between keyframes

### Performance

- **Hot path**: zero impact (walls applied after rebuild, not per-frame)
- **Rebuild path**: ~1-2 ms overhead to draw wall segments (negligible vs total rebuild time)
- **Memory**: ~few KB for wall segments (negligible vs keyframe storage)

## STL Mesh Requirements

### Format
- Binary or ASCII STL
- Wall triangles in 3D space (XYZ coordinates in meters)
- No specific coordinate frame required (uses world frame from SLAM poses)

### Content
- Static walls only (not furniture, not movers)
- Reasonable wall height range (0-2m by default)
- Segments merged/deduplicated within 5cm tolerance

### Recommended Workflow
1. Capture 3D scan of house (e.g., LiDAR, photogrammetry)
2. Extract wall surfaces (filter out furniture, people, etc.)
3. Simplify mesh to keep only walls
4. Export as STL
5. Set `KEVIN_WALLS_STL_PRIOR` path

## Troubleshooting

### "file not found" message
```
walls_stl_prior: file not found: /path/to/walls.stl (disabled)
```
**Fix**: Check that file path is correct and file exists

### "failed to load" message
```
walls_stl_prior: failed to load /path/to/walls.stl: <error> (disabled)
```
**Fix**: Check STL file format (binary or ASCII), verify not corrupt

### No wall evidence appearing
- Check that `KEVIN_WALLS_STL_PRIOR` is set correctly
- Verify SLAM loop closures are happening (check `loop_closures` stat)
- Wall evidence only injected after loop closure + rebuild

### Walls appear in wrong location
- Verify STL coordinate frame matches SLAM world frame
- Check that SLAM pose estimates are converging (watch `max_shift` after loop closure)
- Walls projected using SLAM map origin (ORIGIN_X, ORIGIN_Y, PX_SIZE)
